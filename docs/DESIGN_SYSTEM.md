## 1. 维护说明

1. 本文件是前端实现的**唯一设计令牌来源**；demo 与 Vue 组件不得引入本文件之外的颜色值。
2. 需求变化导致 UI 变化时，先更新 `REQUIREMENTS.md`，再同步本文件与 demo。
3. 令牌命名与取值以本文档表格为准；实现时映射为 CSS 自定义属性，并通过 `web/src/styles/app.css` 的 `@theme inline` 暴露给 Tailwind。
4. 组件样式使用 Tailwind CSS 4 utility；跨组件重复组合放在 `web/src/styles/ui.ts`，使用完整静态类名，不新增 SFC `scoped` 样式块或运行时拼接类名片段。为保持既有浏览器默认排版，项目不启用 Preflight；880px 移动规则统一使用 `shell-down:`。
5. 每次更新同步版本、日期和文末变更记录。

## 2. 设计原则

1. **GitHub 式应用外壳**：左侧全局导航 + 中央信息流列；结构清晰、密度适中、入口永不丢失。
2. **平面优先**：按钮与容器默认无投影、无位移悬浮；层级靠边框、底色和间距表达。仅移动端悬浮按钮保留投影。
3. **黑白品牌**：品牌为黑白手绘风（见第 8 章），正文界面用中性灰系 + 单一主色；AI 身份是唯一允许的第二种"身份色"。
4. **两色叙事**：主色（蓝）用于链接与选中；AI 靛紫用于 AI 身份；点赞红用于情感反馈。其余一切保持中性。
5. **令牌驱动主题**：所有颜色必须通过令牌引用；主题切换只是令牌值的切换（多主题，见第 8 章）。

### 4.1 字体族

- 正文行宽：信息流列宽 = 壳宽 − 侧栏（236px）− 间隙（20px）− 页面留白；在 1440px 级别屏幕上约 620px（40–45 个汉字/行），更宽的屏幕按壳宽比例放大。

### 5.3 响应式

- 断点 **880px**：以下隐藏侧栏，改为「顶部条（品牌 + 主题选择 + 通知）+ 底部导航（全站/搜索/发布/通知/我的）」。
- 宽屏（> 1567px）：壳宽取视口的 60%（约 3/5），最小 940px、最大 1760px 居中；信息流列随壳宽自适应，不再固定 620px。单图缩略图按列宽 72% 展示（移动端恢复全宽），图片网格与视频高度随视口放大（`clamp()`），避免宽卡片里媒体显得过小。
- 表单页（登录、注册、404、设置）保持 620px 窄栏（`ui.narrow`），信息流、列表、详情与编辑器页使用随壳宽自适应的 `ui.constrain`。
- 帖子媒体网格：2 张及以上统一 2 列网格；单图占列宽 72%（移动端全宽），媒体高度随视口放大。
- 移动端互动按钮间距压缩到 10px。

## 6. 按钮规范（GitHub 式）

四类按钮，互不混用：

### 6.1 主按钮（发布 / 快速发布 / 移动端悬浮）

- 令牌：`--btn-bg` / `--btn-fg` / `--btn-hover`；圆角 9px；字重 600。
- 尺寸：信息流内 `8px 22px`；侧栏整行 `11px 16px`；移动端 48px 圆形。
- 状态：悬停与按压只变底色；**无投影、无位移**（移动端悬浮钮除外，允许一层阴影表达浮起）。
- 焦点：全站统一 `:focus-visible { outline: 2px solid var(--primary); outline-offset: 2px }`。

### 6.2 边框胶囊按钮（可见性选择等）

- 底 `--surface`、1px `--border` 描边、圆角 999px、13px/600 文字。
- 结构：`[图标 15px 次级色] 文字 [下拉箭头 13px]`；悬停底色 `--hover`。

### 6.3 幽灵按钮（编辑框工具、存草稿、关闭、通知铃铛）

- 无边框；图标/文字默认 `--ink-3`，悬停 `--hover` 底 + `--ink` 色。
- 悬停底为**圆角方形**（8px），不使用圆形底；工具图标 34px 见方。
- 工具栏六项：图片、视频、文件、话题、定时、可见性；图标全部单色，**不做彩色悬停**。

### 6.4 互动按钮（评论 / 转发 / 点赞 / 收藏）

- 胶囊 + 13px 计数；默认 `--ink-3`。
- 评论、转发悬停：`--primary` 文字 + `--primary-soft` 底。
- 点赞悬停：`--red` + `--red-soft`；已赞：心形填充 `--red`，计数为已赞数。
- 收藏：与评论/转发同款胶囊与悬停；已收藏用 `text-primary` 加粗线框书签图标表达，无计数（收藏完全私有，不展示数量）。
- 计数与 `viewer_state.liked` / `viewer_state.bookmarked` 由接口返回，乐观更新后以服务端为准。

### 6.5 分段筛选（全部 / 人类 / AI）

- 轨道 `--soft`，圆角 10px，内边距 2px；激活项：`--surface` 底 + 1px `--border` + 字重 700。
- 对应接口 `filter=all|human|ai`。

### 6.6 帖子"更多"菜单（⋯）

- 触发：帖子操作统一收进右上角 `⋯` 幽灵图标按钮（18px，`aria-label="更多操作"`，展开时同步 `aria-expanded`），不再默认铺开操作按钮行。
- 浮层：右对齐，`--surface` 底 + 1px `--border` + 10px 圆角 + `--shadow-pop` 投影；菜单项内边距 `7px 10px`、13.5px 文字，悬停 `--hover`。
- 菜单项：编辑（`can_edit`）、历史版本（`can_view_history`）、删除（`can_delete`，`--red` 文字）；是否展示由接口返回字段决定，实际授权仍由后端执行。
- 行为：点击菜单外任意位置或按 Esc 收起；Esc 收起后焦点回到触发按钮。
- 使用范围：首页信息流卡片仅在作者自己的帖子显示；帖子详情页对所有有权查看者显示，非作者只保留历史版本一项。
- 快速发布编辑框复用同一交互：工具行不放"去完整编辑器"文本链接，改为行尾 `⋯` 幽灵按钮，菜单内仅保留"去完整编辑器"入口。
- 实现：`web/src/components/PostActionMenu.vue`，由 `PostCard` 与 `PostDetailView` 共用；快速发布工具行的同款浮层行为抽为通用组件 `web/src/components/MoreMenu.vue`。

## 7. 图标规范

1. **全部图标 SVG 绘制**（需求约束）：24×24 viewBox、`stroke-width: 1.8`（小尺寸可 1.6/2.2）、圆头圆角连接、`stroke: currentColor`、线框风格。
2. 实现方式：同文档 SVG 精灵（`<symbol>` + `<use>`）或组件化按需内联；禁止图标字体、位图与外部图标库图片。
3. 尺寸：内联图标 17–22px；侧栏导航 21px；工具图标 19px；文件/提示等 15–18px。
4. 颜色规则：默认 `--ink-3`，悬停随父级 `--ink`；除互动按钮外不给图标单独上色。
5. 品牌标志与站点图标：`demo/logo.svg`（黑白手绘「潦草印章」），部署时导出 PNG/ICO；界面里的品牌位直接内联同一 SVG。
6. 插画（信息流示例图）为演示占位素材，不属于图标体系；正式环境为上传图片/视频封面，深色主题下统一 `filter: saturate(.75) brightness(.8)`。

## 8. 主题机制

1. `<html data-theme>` 单属性切换，令牌全部挂在该属性下（见第 3 章）。主题注册表在 `web/src/composables/theme.ts`（`THEMES`：id、中文名、预览色点），新增主题 = 注册表加一项 + `tokens.css` 加一块同 id 令牌。
2. 内置主题：浅色（`:root`）、深色（`data-theme="dark"`），扩展配色主题见 3.4（当前为 EVA 初号机/凌波丽/明日香）。默认跟随系统 `prefers-color-scheme` 映射浅/深；手动选择后写入 `localStorage`（键 `tl-theme`）并优先于系统。
3. 首帧防闪：`<head>` 内联脚本按主题白名单校验 `tl-theme` 后先于样式应用主题属性，缺失或非法值回退系统深浅偏好；扩展主题时必须同步该白名单。
4. `color-scheme` 与主题同步声明，保证表单控件与滚动条同主题；扩展主题每套必须定义全部令牌，防止漏配回落默认色。
5. 深浅色差异只允许通过令牌表达；组件代码中禁止出现字面量颜色（插画素材除外）。唯一例外：主题选择器的预览色点是主题注册表的元数据，经内联 style 渲染，不进入组件 CSS。
6. 主题入口为调色板幽灵按钮 + 右对齐浮层选择器（`ThemePicker.vue`，交互同 6.6 的更多菜单：点击外部/Esc 收起、焦点回归），桌面侧栏与移动顶栏共用；每行展示预览色点 + 主题名 + 当前主题勾选。
7. 动效克制：只保留交互反馈过渡（底色 150ms）；`prefers-reduced-motion: reduce` 时全部过渡关闭。

## 9. 页面结构要点（信息流主页）

- 壳布局：`侧栏（sticky，全高分）| 信息流列（自适应宽度、14px 圆角、1px 描边、min-height 100vh）`；壳宽约 3/5 视口并居中，宽屏不额外增加左右栏目。
- 吸顶头部：标题 + 分段筛选；`--glass` 底 + 6px blur + 底部描边；圆角继承列容器上沿。
- 快速发布编辑框：头像 + 描边盒子（输入区 + 工具行）；`:focus-within` 时盒子描边变主色 + 3px `--primary-soft` 光圈；工具行同排依次为可见性、插入表情、添加附件、存草稿、发布，行尾 `⋯` 更多菜单收纳完整编辑器入口，不再展示附件支持范围说明。
- 待处理提示条：`--surface-subtle` 底 + 描边；发件箱图标主色；右侧"去处理"链接与关闭按钮。
- 日期分割：居中细线 + 小字（今天/昨天/日期）。
- 信息流条目：头像 40px + 内容列；作者名/AI 徽章/@用户名/时间成一行折行；操作栏左对齐。
- 转发条目：转发行（图标 + "某某 转发了"）在上；引用卡/占位卡在下。
- 加载行：居中 spinner（14px，`--soft-hover` 轨道 + 主色头）。

### 9.1 内容详情页返回入口

- 从列表进入的内容详情页（帖子详情 P-07）在正文卡片上方提供幽灵样式「← 返回」按钮（13.5px 次级文字，悬停 `--hover` 底 + `--ink` 文字，左侧负偏移与卡片内容对齐）。
- 行为：优先回退浏览器历史（含浏览器自带前进/后退）；直接打开链接、新标签页等没有站内上一页的情况回到全站时间线。加载中、加载失败和「内容不存在」状态同样展示该入口。
- 回退/前进导航由路由恢复离开前的滚动位置：目标页数据异步加载期间，等待内容高度足够后再滚动，避免只能回到页首。

### 9.2 表情选取器

- 发帖/编辑帖编辑器（工具栏「插入表情」幽灵钮，与格式按钮同规格）与快速发布、评论、转发引用、私信输入（输入行幽灵图标钮，`smile` 图标）共用 `EmojiPicker.vue`：触发按钮经插槽由使用方自绘；面板为 fixed 定位浮层（锚定触发钮、视口下方空间不足时向上翻转，z 层级高于转发弹窗遮罩），交互沿用更多菜单范式：点击外部/Esc 收起；面板打开时 Esc 只关闭面板、不触发外层弹窗关闭。
- 第三方实现为 `emoji-picker-element`（web component，随面板首开懒加载分包）：界面文案用库内置 zh_CN 语言包；表情数据用本地 `emoji-picker-element-data` 中文注记数据包（打包为稳定 `data:` URL 注入，无 CDN 外链，内置搜索因此支持中文标签）；「常用」分区由库经 IndexedDB 自动计数维护，仅存于本地浏览器。
- 主题适配：面板容器把库的 CSS 自定义属性（`--background`、`--border-color`、`--input-*`、`--button-hover-background`、`--outline-color` 等）映射到 tokens.css 令牌，随全部主题（含 EVA 扩展主题）自动切换；组件不出现字面量颜色。
- emoji 以纯文本插入正文光标处（编辑器走 `insertText` 保留撤销栈；textarea 按 selection 拼接并同步 v-model），经后端既有清洗与渲染管线，不引入新接口或存储。

### 9.3 个人主页头部横幅

- 个人主页资料卡顶部为全宽横幅区：高 144px（≤880px 壳宽 112px），宽度撑满卡片、上沿继承卡片 14px 圆角裁剪；有横幅时 `<img>` 以 `object-cover` 等比裁剪填充，未设置或加载失败时显示 `--soft` 令牌占位底色，下沿 1px 描边与卡体内容区分隔。
- 头像行、简介与统计仍在卡片内边距内，不与横幅重叠；横幅不做遮罩文字。
- 资料设置页提供横幅预览（10px 圆角描边盒，同一裁剪方式）与「上传/更换横幅」「移除横幅」按钮（次级小按钮规格），交互沿用头像上传范式（隐藏 file input + 成功后同步当前用户）。

### 9.4 群聊占位头像与成员管理

- **群头像占位**：群聊没有头像上传，列表与对话页使用群名首字圆形色块占位——圆形（999px 胶囊体系，同用户默认头像尺寸 40px），底色复用 `--avatar-bg`、字色 `--avatar-bg` 对应的 `--avatar-fg`，显示群名第一个字符；已解散群（`status=dissolved`）整块置灰（`--soft` 底 + `--ink-3` 字色）并保留只读入口，不使用红色等错误色。
- **群成员列表**：沿用信息流条目范式——头像 40px + 昵称/@用户名 + 右侧角色徽章（「群主」复用 11px 徽章小片规格，普通成员不显示徽章）；行尾「移除」入口仅群主可见，使用幽灵按钮、危险语义时文字用 `--red`。
- **群管理表单**：建群与改名使用 620px 窄栏表单范式（`ui.narrow`）；拉人按用户名逐个输入（一次 1–20 人），错误逐人由后端文案提示；解散群为 `--red` 危险按钮并二次确认；转让群主选择在群成员列表内完成（选择目标 + 确认）。
